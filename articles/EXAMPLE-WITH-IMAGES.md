Each image will be:
- Downloaded automatically
- Added to WordPress media library
- Displayed with its caption/credit
- Properly attributed

## Image Format

The syntax is simple:

```markdown
![Alt text for SEO](image-url "Credit/Attribution text")
```

**Components:**
- `![...]` - Alt text (appears if image fails, used by screen readers)
- `(url)` - Direct link to the image
- `"..."` - Credit/caption (visible under image)

## Free Image Sources

Use these sites for free, legal images:

- **Unsplash** - High-quality photos (attribution required)
- **Pexels** - Stock photos (attribution appreciated)
- **Pixabay** - Various images (no attribution needed)

## Best Practices

1. **First image** = Featured image (shows in listings)
2. **Always include credits** when required by the source
3. **Use descriptive alt text** for SEO and accessibility
4. **Choose relevant images** that support your content

Sudoku, graded honestly.

I play Sudoku almost every day, and I still get stuck. So I built the site I wanted. Every puzzle here is solved one move at a time, the way you'd do it, and the hardest move sets the level. Not the number of clues.

Start with Easy if you're new, or jump into Not Easy, which plays a lot like the NYT Medium. Try the daily puzzle if you want the same grid as everyone else today.
